# Generative Modeling

26秋生成模型基础课程的个人学习记录留档，包括课程笔记、作业解答、论文阅读材料和考试复习资料。

## 目录

| 文件夹 | 内容 |
| --- | --- |
| `assignment/` | 作业题目、个人解答及 LaTeX 源文件 |
| `notes/` | 按主题整理的学习笔记 |
| `paper/` | 作业和课程涉及的论文 |
| `review/` | 往年试题、理论复习笔记及按知识点整理的题库 |
| `slides/` | 课程课件 |

## 学习内容

- 变分自编码器（VAE）与重参数化
- 自回归模型（AR）与 Transformer
- 生成对抗网络（GAN）
- 扩散模型与 DDPM
- 指令微调与基于人类反馈的强化学习（RLHF）
